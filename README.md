# java-calculator-precourse
 1. 입력처리 및 유효성 검사 

    1.1 입력 문자열 받기 : 사용자로부터 덧셈할 문자열을 입력받는다.

    1.2 예외처리(빈 문자열) : 입력이 빈 문자열 또는 null인 경우 0을 반환한다

    1.3 예외처리(음수 또는 숫자를 제외한 문자) : 입력 문자열에 음수 또는 숫자가 아닌 문자가 포함된 경우 IllegalArgumentException을 발생시키고 애플리케이션은 종료한다.

 2. 문자열 분리 기능

    2.1 기본 구분자 처리 : 문자열에 쉼표, 콜론이 포함된 경우 이들을 구분자로 사용하여 문자열을 분리한다.

    2.2 커스텀 구분자 정의 : 문자열이 // 와 \n 사이의 커스텀 구분자를 포함한 경우 해당 문자를 구분자로 사용한다.

    2.3 단일 숫자 처리 : 입력 문자열이 구분자 없이 숫자 하나만 있는 경우, 해당 숫자를 반환한다.

 3. 덧셈 기능

    3.1 숫자 합산 : 분리된 문자열 배열의 각 요소를 숫자로 변환하고, 값들을 합산하여 최종 결과를 반환한다.

 4. 실행 및 출력 기능

    4.1 입력 요청 메시지 출력 : 프로그램 실행 시 사용자에게 '덧셈할 문자열을 입력해 주세요.' 메시지를 출력한다.

    4.2 최종 결과 출력 : 계산이 완료되면 최종 덧셈 결과를 출력한다.

    4.3 예외 발생 시 종료 : 예외가 발생 시 IllegalArgumentException을 발생시킨 후 프로그램을 종료한다.
